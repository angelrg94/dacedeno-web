# Daniela Cedeño — primer mock

## Dirección

Una marca de bienestar activa y cercana: la comida y el movimiento como partes de una misma vida, no como disciplina punitiva. El gesto gráfico principal es una línea continua que une nutrición, fuerza y acompañamiento.

## Tokens — paleta Daniela

- Oliva sereno — `#87906A`: identidad, movimiento y superficies destacadas.
- Salvia — `#AEBA9C`: calma, comunidad y acentos orgánicos.
- Blanco cálido — `#FFFEFF`: superficie principal y aire visual.
- Marfil — `#FAF3DE`: portada y zonas de descanso.
- Arena — `#E2C69B`: cercanía, firma y detalles humanos.
- Oliva profundo — `#566046`: derivado funcional para botones y fondos con contraste accesible.
- Tinta vegetal — `#20251C`: derivado oscuro para texto accesible.

Tipografía: Bricolage Grotesque para titulares y Manrope para lectura, navegación y controles.

## Fotografía real

- Portada: retrato vertical de Daniela entrenando con pesa rusa. El encuadre conserva rostro, postura y el gesto de fuerza; se mantiene el arco como marco característico de la marca.
- Método: fotografía horizontal de Daniela realizando una zancada en el parque. El recorte prioriza su figura y aporta contexto real de entrenamiento al aire libre.
- Tratamiento: color natural moderado para integrarlo con la paleta verde, dimensiones declaradas para evitar saltos de página y carga diferida solo en la imagen secundaria.
- Las dos fotos sustituyen las imágenes referenciales de Unsplash; el mock deja de depender de fotografías externas.

## Layout

Contenido mayormente alineado a la izquierda, con una portada asimétrica 55/45, bloques de servicio en franjas y una agenda que se comporta como un pequeño módulo práctico, no como decoración.

```text
┌─────────────────────────────────────────────────────────┐
│ marca        servicios  programas  sobre mí     agenda │
├───────────────────────────────┬─────────────────────────┤
│ Comer bien.                   │      retrato curvo      │
│ Moverte mejor.                │   + notas personales    │
│ [agendar] [programas]         │                         │
├───────────────────────────────┴─────────────────────────┤
│ manifiesto en movimiento / frase continua              │
├─────────────────────────────────────────────────────────┤
│ servicios en tres franjas amplias y diferenciadas      │
├───────────────────────────────┬─────────────────────────┤
│ programas y productos        │ programa destacado      │
├───────────────────────────────┴─────────────────────────┤
│ historia / método  ─────────── agenda práctica          │
├─────────────────────────────────────────────────────────┤
│ testimonios, preguntas frecuentes y contacto           │
└─────────────────────────────────────────────────────────┘
```

## Principios

- Hablar de capacidad, energía y hábitos; nunca de culpa o cuerpos ideales.
- Formas curvas solo donde comunican cuerpo, plato o movimiento.
- Una única entrada animada y microinteracciones que responden a acciones reales.
- Copia simple, chilena/latinoamericana neutra y conversacional.

## Prueba social real

Los nueve mensajes compartidos por clientes se incorporan como fragmentos editoriales, no como capturas de WhatsApp. Un carrusel de navegación manual permite leerlos a ritmo propio; cada testimonio se identifica por el tipo de proceso y mantiene reservada la identidad de la persona. La gran escala tipográfica convierte la voz de las clientes en el elemento principal de la sección, mientras el contador y el índice muestran que existe una comunidad amplia sin inventar nombres, fotografías ni resultados.

## Revisión de singularidad

La paleta entregada podía acercar el sitio al patrón habitual “wellness beige”. Para evitarlo se conservan los titulares sans de gran escala, la composición asimétrica, las franjas de contenido y el trazo gestual. Los tonos claros dan cercanía; el oliva profundo mantiene fuerza, legibilidad y una identidad menos decorativa.
